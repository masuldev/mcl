# MCL v1.3.0 릴리즈 노트

## 🎨 UI/UX 완전 개편 (Major Update)

### ⚡️ Survey → Bubbletea 마이그레이션
- **모던 TUI 프레임워크**: 기존 Survey에서 최신 Bubbletea로 완전 전환
- **Dracula 테마 적용**: 개발자 친화적인 아름다운 다크 테마 도입
- **이모티콘 제거**: 색상 기반 시각적 피드백으로 전문적인 느낌 구현

### 🔍 검색 변경
- **검색어 하이라이트**: 입력한 검색어가 Yellow Bold로 강조 표시
- **스마트 검색 지우기**: Esc 키로 검색어 먼저 지우고, 다시 누르면 종료
- **Ctrl+U**: 검색어 전체 즉시 삭제

### 🎯 향상된 네비게이션
- **페이징 완전 지원**: PgUp/PgDn으로 빠른 페이지 이동
- **Vim 스타일 키바인딩**: j/k 키로 상하 이동
- **페이지 정보 표시**: "Page 1/5 | Total: 47 items" 실시간 표시
- **선택 항목 강조**: CurrentLine 배경색으로 명확한 선택 표시

### ✨ 고급 텍스트 편집 기능
- **커서 위치 시각화**: 실시간 커서 위치 표시
- **고급 편집 단축키**:
  - `Ctrl+W`: 단어 단위 삭제
  - `Ctrl+K`: 커서부터 줄 끝까지 삭제
  - `Ctrl+U`: 커서부터 줄 시작까지 삭제
  - `Home/End`: 줄 시작/끝으로 이동
- **Insert 모드**: 커서 위치에 문자 삽입 가능

## 🚀 성능 대폭 개선

### ⚡️ 속도 향상
- **10-30% 응답속도 개선**: strings.Builder 사용으로 문자열 처리 최적화
- **검색 모드 제거**: 불필요한 상태 전환 제거로 키 입력 지연 감소
- **조건부 렌더링**: 필요한 부분만 스타일 적용하여 CPU 사용량 감소

### 💾 메모리 최적화
- **효율적인 문자열 구성**: 메모리 할당 횟수 감소
- **스타일 객체 최적화**: lipgloss 스타일 효율적 사용
- **페이징 로직 단순화**: 불필요한 계산 제거

## 🏗️ 아키텍처 개선

### 🔄 Clean Architecture 도입
- **Service Layer 패턴**: 비즈니스 로직과 UI 완전 분리
- **Adapter Pattern**: Bubbletea/Fallback 모드 자동 선택
- **Dependency Injection**: 서비스 초기화 구조 개선

### 📦 패키지 구조 개선
```
internal/
├── ui/                    # 새로운 UI 시스템
│   ├── service.go         # 메인 프롬프트 서비스
│   ├── types.go           # 인터페이스 정의
│   ├── bubbletea_adapter.go  # Bubbletea 구현
│   └── fallback_adapter.go   # 호환성 모드
├── ask.go                 # Ask 함수들 (UI 서비스 사용)
├── auth.go                # 인증 (UI 의존성 제거)
└── constants.go           # 공통 상수
```

## 🚀 사용법

### 🎨 새로운 UI 경험
```bash
# EC2 인스턴스 선택 - 즉시 타이핑으로 검색
mcl ec2
# 타이핑하면 바로 필터링됩니다!

# RDS 인스턴스 - 페이징 지원
mcl rds
# PgUp/PgDn으로 빠른 페이지 이동

# S3 버킷 - 고급 키바인딩
mcl s3 --list-objects
# j/k, Ctrl+U, Home/End 등 사용 가능
```

### 🔧 환경 설정
```bash
# Fallback 모드 강제 사용 (CI/CD 등)
MCL_UI_ADAPTER=fallback mcl ec2

# 디버그 모드
MCL_DEBUG=true mcl ec2
```
